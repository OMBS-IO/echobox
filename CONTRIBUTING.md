# Contributing to Echobox

Thanks for your interest in Echobox! This document explains how you can participate in the community.

## About This Repository

Echobox is **not open source** — the source code is proprietary and not available in this repository. This repo exists as a **community hub** for:

- Bug reports
- Feature requests
- Audio quality issues
- General feedback and discussion

## How to Contribute

### Report a Bug

1. Check [existing issues](https://github.com/OMBS-IO/echobox/issues) to avoid duplicates
2. Use the **Bug Report** template when creating a new issue
3. Include your Echobox version, device model, Android version, and output device
4. Attach signal path diagnostics if relevant (found in the app's settings)

### Request a Feature

1. Check [existing issues](https://github.com/OMBS-IO/echobox/issues) and [discussions](https://github.com/OMBS-IO/echobox/discussions) first
2. Use the **Feature Request** template
3. Describe the problem you're trying to solve, not just the solution you want

### Report an Audio Quality Issue

For audio-specific problems (clicks, pops, dropouts, distortion, DAC issues), use the **Audio Quality Issue** template. This helps us collect the technical details needed to diagnose audio problems.

### Vote on Issues

If you want to see a feature implemented or a bug prioritized, add a thumbs-up reaction to the issue. We use reaction counts to help gauge community demand.

### Join the Discussion

- [GitHub Discussions](https://github.com/OMBS-IO/echobox/discussions) — Feature ideas, Q&A, audio setup showcases
- [Reddit](https://reddit.com/r/echobox) — Broader discussion

### Improve Documentation

Found a typo or want to improve the docs in this repo? Pull requests for documentation changes are welcome. Use the PR template and keep changes focused.

## What We Can't Accept

Since Echobox is not open source, we cannot accept:

- Source code contributions
- Pull requests for app functionality
- Reverse-engineered code or assets

## Response Times

Echobox is developed by a small team. We read every issue and piece of feedback, but response times may vary. Critical bugs and audio quality issues are prioritized.

## Code of Conduct

We are committed to providing a welcoming and inclusive experience for everyone. Please be respectful and constructive in all interactions.
